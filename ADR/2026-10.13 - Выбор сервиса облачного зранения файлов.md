
**ADR: 2026-10.11 - Выбор сервиса облачного хранения файлов**

**Дата:** 21 октября 2026 г.

**Статус:** Принято

**Контекст:**

В приложении EduRate необходимо предусмотреть хранение файлов, загружаемых пользователями и используемых серверной частью.

В частности, пользователи могут загружать документы, подтверждающие факт обучения в образовательной организации или прохождения курса. Такие документы используются модераторами для проверки достоверности отзывов.
Кроме того, необходимо предусмотреть возможность хранения резервных копий данных системы.

Хранилище должно обеспечивать надёжность сохранения файлов, масштабируемость, возможность программного взаимодействия с серверной частью и защиту персональных данных.

При выборе сервиса особое внимание необходимо уделить соблюдению требований Федерального закона № 152-ФЗ «О персональных данных», поскольку загружаемые документы могут содержать персональные данные пользователей.


**Рассмотренные варианты:**

1. **Selectel Object Storage:** облачное объектное хранилище, поддерживающее S3 API. Позволяет сохранять файлы и обращаться к ним программно из серверной части приложения.
2. **Yandex Object Storage:** облачное объектное хранилище от Yandex Cloud, поддерживающее S3 API и предоставляющее средства управления файлами.
3. **VK Cloud Object Storage:** облачное объектное хранилище, предназначенное для сохранения файлов и работы с ними через API.


**Решение:**

Выбран Selectel Object Storage.

**Обоснование:**

- **Поддержка S3 API:** позволяет взаимодействовать с хранилищем из серверной части Django с использованием стандартных инструментов и библиотек для работы с S3-совместимыми хранилищами.
- **Соответствие требованиям 152-ФЗ:** Selectel заявляет о соответствии сервиса S3 требованиям ФЗ-152. При этом необходимо учитывать распределение ответственности между провайдером и заказчиком.
- **Масштабируемость:** объектное хранилище позволяет увеличивать объём сохраняемых файлов без необходимости самостоятельно управлять физическими накопителями.
- **Надёжность хранения:** распределённая инфраструктура провайдера снижает необходимость самостоятельного обслуживания оборудования.
- **Разделение хранения данных:** позволяет хранить пользовательские документы отдельно от основной базы данных PostgreSQL.
- **Поддержка резервного копирования:** хранилище можно использовать для размещения резервных копий данных системы.

**Последствия:**
- Необходимо создать отдельные бакеты для хранения подтверждающих документов и резервных копий.
- Серверная часть должна взаимодействовать с хранилищем через S3 API.
- Доступ к хранилищу должен осуществляться только с серверной стороны. Мобильное приложение не должно получать постоянные ключи доступа к облачному хранилищу.
- Необходимо ограничить публичный доступ к бакетам с пользовательскими документами.
- Для передачи файлов пользователям и модераторам следует предусмотреть временные ссылки с ограниченным сроком действия либо выдачу файлов через серверную часть.
- Необходимо настроить разграничение прав доступа к документам в зависимости от роли пользователя.
- Следует предусмотреть проверку загружаемых файлов, ограничение их размера и допустимых форматов.
- Для резервных копий необходимо настроить регулярное создание копий и периодическую проверку возможности восстановления.
- Необходимо проверить размещение хранилища, условия обработки персональных данных и при необходимости оформить поручение на обработку персональных данных с провайдером.
- Следует учитывать, что Selectel обеспечивает безопасность инфраструктуры сервиса, но правильная настройка доступа и соблюдение требований законодательства остаются ответственностью EduRate.
