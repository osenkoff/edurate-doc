
**ADR: 2026-10.11 - Выбор SMTP-сервиса лдя отправки электронных писем**

**Дата:** 21 октября 2026 г.

**Статус:** Принято

**Контекст:**

В приложении EduRate необходимо реализовать отправку электронных писем пользователям.

Электронная почта будет использоваться для подтверждения адреса электронной почты, отправки кодов двухфакторной аутентификации, восстановления доступа к учётной записи и передачи других служебных уведомлений.

Необходимо выбрать SMTP-сервис, который позволит серверной части приложения отправлять письма без самостоятельного развёртывания и обслуживания почтовой инфраструктуры.

При выборе решения необходимо учитывать надёжность доставки сообщений, безопасность передачи данных, простоту интеграции с Django и доступность сервиса для проекта.

**Рассмотренные варианты:**

1. **Selectel SMTP:** почтовый сервис Selectel, предоставляющий SMTP-сервер для отправки электронных писем с серверной инфраструктуры приложения.
2. **Yandex 360 для бизнеса:** почтовый сервис Yandex, предоставляющий возможности работы с корпоративной электронной почтой и отправки сообщений через SMTP. 
3. **VK WorkSpace:** корпоративный почтовый сервис с поддержкой работы с электронной почтой и SMTP-клиентами.

**Решение:**

Выбран Selectel SMTP. 

**Обоснование:**

- **Простота интеграции:** сервис поддерживает стандартный протокол SMTP и может использоваться с существующими средствами отправки электронной почты Django. 
- **Защищённая передача данных:** сервис поддерживает передачу информации с использованием TLS.
- **Отсутствие необходимости обслуживать почтовую инфраструктуру:** Selectel обеспечивает работу SMTP-сервера и его техническую поддержку.
- **Поддержка служебных писем:** сервис подходит для отправки кодов подтверждения, восстановления доступа и других транзакционных сообщений.
- **Интеграция с серверной частью:** для подключения достаточно настроить параметры SMTP-соединения, учётные данные и домен отправителя.
- **Журналирование операций:** сервис предоставляет возможность отслеживать операции отправки сообщений.

**Последствия:**
- Необходимо подключить Selectel SMTP и зарегистрировать домен отправителя.
- В серверной части Django следует настроить параметры SMTP-соединения, включая адрес сервера, порт, учётные данные и использование TLS.
- Данные для подключения должны храниться в переменных окружения или защищённом хранилище секретов.
- Необходимо настроить DNS-записи домена, включая SPF, DKIM и DMARC, если они поддерживаются используемой конфигурацией.
- Следует реализовать отправку писем для подтверждения электронной почты, двухфакторной аутентификации и восстановления доступа.
- Необходимо предусмотреть обработку ошибок отправки и повторные попытки при временной недоступности SMTP-сервиса.
- Следует вести журнал результатов отправки без сохранения паролей, кодов подтверждения и других секретных данных.
- Необходимо ограничить частоту отправки писем для предотвращения злоупотреблений и массовой рассылки.
- Следует учитывать срок действия кодов подтверждения и обеспечивать их одноразовое использование.
